# Vistoria de Recebimento

App de vistoria de recebimento de apartamento. Abre no navegador, funciona sem internet e pode ser instalado na tela inicial do celular.

Link: https://humbertopaiva25.github.io/vistoria/

## Instalar no celular
- Android (Chrome): abra o link e toque em "Instalar" no aviso, ou no menu de três pontos > "Instalar app".
- iPhone (Safari): abra o link, toque em Compartilhar > "Adicionar à Tela de Início".

Os dados de cada pessoa ficam só no celular dela. Para trocar de aparelho, use o backup dentro do app.

## Atualizar o app
Ao mudar qualquer arquivo, troque a versão na primeira linha de código de `sw.js` (ex.: `vistoria-v2`) para os celulares pegarem a nova versão.
